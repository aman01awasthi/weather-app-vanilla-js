# Weather App

A vanilla JavaScript weather app that fetches real-time weather data using the OpenWeatherMap API.

## Features
- Search weather by city name
- Displays temperature, description, humidity, and wind speed
- Handles invalid city, empty input, and network errors
- Remembers last searched city using localStorage
- No libraries or frameworks — pure HTML, CSS, and JS

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
3. Enter a city name and click Search

## API Used
[OpenWeatherMap](https://openweathermap.org/api) — free tier
